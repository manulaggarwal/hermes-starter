# knowledge/ — durable memory for this repo

- `../LIMITS.md` — what this repo doesn't do (canonical; README links here)
- `../docs/HEADROOM.md` — the token-budget philosophy (the differentiator)
- This directory stays deliberately tiny: two pointers, no duplication.
  The full convention lives in templates/knowledge-readme.md — one topic per
  file, daily-logs capture what happened, knowledge captures what's true.
