# AGENT.md — navigation for agents

> Any AI agent working in this vault reads this first.

## How to navigate
- Project work lives in project repos (or project dirs) — this vault is
  navigation + durable knowledge, not the workspace itself
- `02-Knowledge/_index.md` lists topics
- `03-Daily/` is available for vault-side journaling; if a project keeps its
  own `daily-logs/`, THAT is canonical for project work (project > vault)

## Rules
1. The repo (if any) is canonical; this vault navigates
2. Never edit historical logs — append, don't rewrite
3. Wikilinks beat prose for connections: [[note-name]]
